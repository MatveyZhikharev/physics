# Трассировка лучей в оптических системах

## Общая идея

Симулятор моделирует прохождение световых лучей через оптическую систему методом **геометрической оптики**. Каждый луч задаётся точкой старта и направлением; на каждой оптической поверхности направление меняется по закону преломления. Строятся лучи от трёх точек объекта (верхушка, центр, низ) — по ним определяется положение и размер изображения.

***

## Режим 1 — Тонкие линзы (микроскоп)

### Модель тонкой линзы

Тонкая линза считается бесконечно тонкой плоскостью. При прохождении через неё луч мгновенно меняет угол наклона по правилу:

```
α_out = α_in − y / f
```

где `y` — высота луча на линзе, `f` — фокусное расстояние.

### Схема микроскопа

```
Объект → [L₁ объектив] → промежуточное изображение → [L₂ окуляр] → финальное изображение
```

1. Луч стартует из точки объекта под углом `α`
2. Распространяется прямолинейно до плоскости линзы L₁ (z = obj_dist)
3. Преломляется: `α ← α − y/f₁`
4. Летит до L₂ (z = obj_dist + tube_length)
5. Преломляется: `α ← α − y/f₂`
6. Летит дальше — пересечение лучей даёт изображение

### Проверка формулы тонкой линзы

Положение изображения вычисляется аналитически и сравнивается с трассировкой:

```
1/v₁ = 1/f₁ + 1/u₁        (u₁ = obj_dist)
u₂   = tube_length − v₁
1/v₂ = 1/f₂ + 1/u₂

M_total = m₁ · m₂ = (−v₁/u₁) · (−v₂/u₂)
```

Если лучи сходятся именно там, куда указывает формула — модель валидна.

***

## Режим 2 — Толстая сферическая линза

### Геометрия линзы

Двояковыпуклая линза задаётся двумя сферическими поверхностями:

```
Передняя поверхность:  центр кривизны в  z_front + R1
Задняя  поверхность:   центр кривизны в  z_back  − R2
```

Это обеспечивает выпуклость с обеих сторон при положительных R1, R2.

### Пересечение луча со сферой

Луч: `P(t) = P₀ + t·d`

Подставляется в уравнение сферы `|P − C|² = R²`, получается квадратное уравнение:

```
a·t² + b·t + c = 0
a = |d|²
b = 2·(P₀−C)·d
c = |P₀−C|² − R²
```

Берётся наименьший положительный корень `t` — это первая точка пересечения.

### Преломление по закону Снеллиуса (векторная форма)

В точке пересечения вычисляется нормаль к сфере:

```
n̂ = (hit − center) / |hit − center|
```

Затем применяется векторный закон Снеллиуса:

```
d_out = (n₁/n₂)·d_in + (n₁/n₂·cos θᵢ − cos θₜ)·n̂

где  cos θᵢ = −d_in · n̂
     cos θₜ = √(1 − (n₁/n₂)²·sin²θᵢ)
```

Если `sin²θₜ > 1` — полное внутреннее отражение, луч обрывается.

### Формула толстой линзы (для сравнения)

Фокусное расстояние EFL вычисляется аналитически через оптические силы поверхностей:

```
P₁ = (n − 1) / R1
P₂ = (n − 1) / R2
EFL = 1 / (P₁ + P₂ − d/n · P₁·P₂)
```

Результат трассировки сравнивается с этим предсказанием — отклонение `Δ` показывает влияние **сферической аберрации**.

***

## Яркость и телесный угол

При преломлении изменяется телесный угол пучка. Из закона сохранения энергии (теорема Клаузиуса):

```
L · n² = const
```

где `L` — яркость (radiance), `n` — показатель преломления среды. Это означает, что при входе в стекло (n > 1) яркость пучка возрастает пропорционально `n²`, а при выходе — падает обратно. В симуляторе интенсивность отражений не учитывается (по условию задачи), поэтому полная энергия каждого луча считается сохранённой.
