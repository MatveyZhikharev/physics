# Численное моделирование электростатических систем методом моментов (MoM)

Данный проект реализует численное решение фундаментальной краевой задачи электростатики: нахождение распределения поверхностных зарядов, расчет векторов напряженности электрического поля и определение взаимной емкости системы проводников произвольной формы.

## 1. Условия задачи

Для моделирования выбрана система из двух проводников (например, две сферы — вложенные или разнесенные в пространстве, либо две параллельные пластины), работающая в следующих условиях:

* **Потенциалы:** На электродах поддерживается фиксированная разность потенциалов $\Delta\phi = V$. В расчетной схеме потенциалы задаются симметрично: $\phi_1 = +V/2$ и $\phi_2 = -V/2$.
* **Заряды:** Система считается электрически нейтральной, поэтому полные заряды электродов противоположны по знаку и строго одинаковы по модулю ($Q_1 = -Q_2$).
* **Дискретизация:** Поверхность каждого проводника разбивается на $N$ малых плоских элементов (панелей) одинаковой формы.
* **Метод расчета:** Необходимо вычислить дискретные заряды $q_i$ для каждого элемента поверхности, при которых потенциал в центре элемента соответствует заданному граничному условию.

**Ожидаемые результаты:**
1. Пространственное распределение вектора напряженности $\mathbf{E}$.
2. Картина силовых линий поля.
3. Расчетная емкость системы $C = |Q|/V$.

---

## 2. Математическая модель

### Определение потенциала
В данной задаче потенциал $\phi(\mathbf{r})$ определяется как неопределенный интеграл от вектора напряженности электрического поля. Константа интегрирования выбирается таким образом, чтобы выполнялось граничное условие — потенциал равен нулю на бесконечности ($\phi(\infty) = 0$):

$$\phi(\mathbf{r}) = -\int \mathbf{E} \cdot d\mathbf{l}$$

Для дискретной системы из $N$ точечных зарядов потенциал рассчитывается как суперпозиция их полей:

$$\phi(\mathbf{r}) = \frac{1}{4\pi\epsilon_0} \sum_{j=1}^{N} \frac{q_j}{|\mathbf{r} - \mathbf{r}_j|}$$

### Метод моментов (Method of Moments)
Задача сводится к решению системы линейных алгебраических уравнений (СЛАУ):

$$\mathbf{A} \cdot \mathbf{q} = \mathbf{V}$$

Где элементы матрицы $\mathbf{A}$ рассчитываются следующим образом:

* **Взаимное влияние ($i \neq j$):** Потенциал от заряда панели, принимаемого за точечный:

$$A_{ij} = \frac{1}{4\pi\epsilon_0 |\mathbf{r}_i - \mathbf{r}_j|}$$

* **Самовлияние ($i = j$):** Аппроксимация элемента диском площади $S_i$ для устранения математической сингулярности в центре собственной панели:

$$A_{ii} = \frac{1}{4\pi\epsilon_0} \frac{2}{\sqrt{S_i / \pi}}$$

## 3. Расчет полей и визуализация

После решения СЛАУ и нахождения зарядов $q_j$ рассчитываются физические поля:

1. **Напряженность поля:** Векторная сумма вкладов всех элементов в любой точке пространства:

$$\mathbf{E}(\mathbf{r}) = \frac{1}{4\pi\epsilon_0} \sum_{j=1}^{N} \frac{q_j (\mathbf{r} - \mathbf{r}_j)}{|\mathbf{r} - \mathbf{r}_j|^3}$$

2. **Силовые линии:** Строятся как линии тока вектора $\mathbf{E}$. Они всегда перпендикулярны эквипотенциальным поверхностям и направлены от положительного заряда к отрицательному.

---

## 4. План тестирования и верификации

Для проверки корректности численного решения используются следующие тесты:

| № | Тест | Метод проверки | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **1** | **Баланс заряда** | Суммирование всех $q_i$. | Сумма $\sum q_i \approx 0$ (с точностью машинного нуля, $\sim 10^{-12}$). |
| **2** | **Эквипотенциальность** | Проверка $\phi$ между узлами сетки на поверхности. | Отклонение от заданных $\pm V/2$ должно быть минимальным. |
| **3** | **Поле внутри** | Расчет $\mathbf{E}$ в любой внутренней точке проводника. | $\mathbf{E} \approx 0$ (согласно электростатической теореме Гаусса). |
| **4** | **Сходимость** | Расчет емкости $C$ при разном числе элементов $N$. | Значение $C$ должно стабилизироваться с ростом густоты сетки $N$. |
