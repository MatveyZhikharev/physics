Этот проект реализует численное моделирование продольных волн в цепочке грузов, соединённых пружинами, с поддержкой настройки параметров из консоли и режимов бегущих и стоячих волн .

## Проект M6. Волны на цепочке

### Условие

Смоделировать продольные колебания длинной одномерной цепочки из \(N \ge 100\) одинаковых грузов массы \(m\), соединённых пружинами жёсткости \(k\). Рассмотреть два режима:
1. Возбуждение волны на краю цепочки (импульсом или гармоническим воздействием), анализ её распространения и измерение скорости волны.
2. Стоячие волны при закреплённых концах цепочки при вынужденных колебаниях одного из грузов с учётом слабого трения для исследования резонанса.[1]

Параметры системы (число грузов, масса, жёсткость, трение, режим) задаются пользователем через консоль с разумными значениями по умолчанию .

## Теория

### Дискретная цепочка и волновое уравнение

Рассматривается цепочка из \(N\) масс \(m\), соединённых пружинами жёсткости \(k\) с шагом \(a\). Для продольных смещений \(x_i(t)\) уравнение движения внутреннего узла имеет вид:
\[
m \ddot{x}_i = k(x_{i+1} - x_i) - k(x_i - x_{i-1}) - \gamma \dot{x}_i,
\quad i = 1,\dots,N-2,
\]
где \(\gamma\) — коэффициент вязкого трения.[1]

В непрерывном пределе это приводит к волновому уравнению:
\[
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad c = a\sqrt{\frac{k}{m}},
\]
где \(c\) — фазовая скорость продольной волны в эффективной «струне».[1]

### Собственные частоты и стоячие волны

При жёстко закреплённых концах цепочки (\(x_0 = x_{N+1} = 0\)) собственные частоты дискретной системы:
\[
\omega_n = 2\sqrt{\frac{k}{m}}\sin\left(\frac{n\pi}{2(N+1)}\right),\quad n=1,2,\dots,N.
\]

Если систему возбуждать гармонической силой с частотой, близкой к \(\omega_n\), при небольшом трении \(\gamma\) устанавливается стоячая волна с \(n\) пучностями и узлами в точках фиксации.[1]

## Реализация

### Структура кода

Программа состоит из следующих ключевых частей :

- Функция `get_param` — опрашивает пользователя в консоли и возвращает введённое значение либо значение по умолчанию (если пользователь нажал Enter).
- Блок настройки параметров — чтение:
  - числа грузов `N`,
  - массы `m`,
  - жёсткости пружин `k`,
  - коэффициента трения `gamma`,
  - режима моделирования: бегущая (`pulse`) или стоячая (`standing`) волна.
- Класс `ChainSimulation` — инкапсулирует параметры и состояние цепочки:
  - массив смещений `x`,
  - массив скоростей `v`,
  - текущее время `t`,
  - расчёт теоретической скорости волны \(c\) и частоты возбуждения для выбранной моды при стоячих волнах.
- Анимационный блок с использованием `matplotlib.animation.FuncAnimation` для визуализации смещения всех грузов во времени.

### Уравнения и численный метод

Для внутреннего узла цепочки численная модель реализует систему:
- Сила:
  \[
  F_i = k(x_{i+1} - 2x_i + x_{i-1}) - \gamma v_i + F_{\text{drive},i}(t),
  \]
  где \(F_{\text{drive},i}\) — внешняя сила (в режиме стоячей волны — гармоническое возбуждение одного из грузов) .
- Скорость и координата интегрируются методом Верле (Velocity Verlet):
  - полушаг по скорости,
  - шаг по координате,
  - повторный пересчёт силы и завершение обновления скорости.

Граничные условия:
- Режим «бегущая волна» (`pulse`):
  - левый край возбуждается коротким гауссовым импульсом по смещению,
  - правый край условно закреплён (при большом \(N\) отражения приходят поздно).
- Режим «стоячая волна» (`standing`):
  - оба края жёстко закреплены: \(x_0 = x_{N-1} = 0\),
  - на узел вблизи начала цепочки действует гармоническая сила с частотой одной из собственных мод \(\omega_n\) .

### Интерфейс и параметры

При запуске программа предлагает в консоли:

- Ввести:
  - число грузов `N` (по умолчанию 100),
  - массу `m` (по умолчанию 1.0),
  - жёсткость пружины `k` (по умолчанию 1000.0),
  - коэффициент трения `gamma` (по умолчанию 0.05),
- Выбрать режим:
  - `1` — бегущая волна (импульс на краю),
  - `2` — стоячая волна (вынужденные колебания и резонанс).

При пустом вводе используются указанные значения по умолчанию, а текущие параметры дополнительно отображаются на графике в виде подписи .

## Анализ и сравнение с теорией

- В режиме бегущей волны можно измерить скорость распространения импульса, отслеживая время, за которое максимум смещения проходит заданное число узлов, и сравнить с теоретической формулой \(c = a\sqrt{k/m}\).[1]
- В режиме стоячих волн при возбуждении на частоте, близкой к \(\omega_n\), наблюдается устойчивый пространственный профиль с характерным числом узлов и пучностей для выбранной моды; добавление трения приводит к установлению конечной амплитуды резонансных колебаний.[1]
