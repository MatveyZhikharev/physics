# Проект M3. Полёт на Марс: Расчёт траектории космического корабля

## Условие

Рассчитать траекторию отправки космического корабля на Марс. Реализовать расчёт следующих этапов полёта:

1) вертикальный взлёт с поверхности Земли;  
2) движение от орбиты Земли до орбиты Марса с выключенными двигателями в поле тяготения Солнца;  
3) мягкая посадка на поверхность Марса.

Корабль можно считать материальной точкой переменной массы, движущейся без сопротивления, с возможностью включения постоянной реактивной тяги.

*Дополнительные задания*  
A) На этапе 1 рассмотреть старт многоступенчатой ракеты и/или учесть сопротивление атмосферы;  
B) На этапе 2 учесть притяжение планет;  
C) На этапе 3 учесть конечные размеры корабля, считая его цилиндром, и смоделировать работу ориентирующих двигателей для разворота при заходе на посадку.

---

## Теория

### 1. Уравнение движения ракеты (уравнение Мещерского)

Для материальной точки переменной массы:
m(t) * dv/dt = F_тяги + F_внеш

где:
- `m(t)` — текущая масса ракеты,
- `F_тяги = -u * dm/dt * e` — реактивная тяга,
- `u` — скорость истечения газов относительно ракеты,
- `e` — единичный вектор направления тяги,
- `F_внеш` — внешние силы (гравитация, сопротивление и т.д.).

В проекции на вертикаль (для этапа 1):
m * dv/dt = u * dm/dt - m*g

### 2. Вертикальный взлёт с постоянной тягой

Пусть `dm/dt = -α = const` (расход топлива), тогда:
m(t) = m_0 - α*t

Уравнение движения:
dv/dt = (u*α)/m - g

Интегрируя при `v(0) = 0`, получаем:
v(t) = u * ln(m_0/m(t)) - g*t

Высота:
h(t) = ∫[0..t] v(τ) dτ

### 3. Переход на орбиту (вторая космическая скорость)

Для выхода на орбиту Земли необходимо достичь скорости:
v_orb = √(G*M_⊕/(R_⊕ + h_orb))

где:
- `G` — гравитационная постоянная,
- `M_⊕` — масса Земли,
- `R_⊕` — радиус Земли,
- `h_orb` — высота орбиты.

Для отлёта к Марсу требуется вторая космическая скорость (относительно Земли):
v_esc = √2 * v_orb

### 4. Гелиоцентрический перелёт (этап 2, без двигателей)

В поле тяготения Солнца движение описывается уравнением:
d²r/dt² = -(G*M_⊙/r³) * r

где `r` — радиус-вектор от Солнца.

Для перелёта с орбиты Земли на орбиту Марса используется **эллиптическая гомановская траектория**:
- Большая полуось: `a = (R_⊕ + R_Марс)/2`
- Период полуэллипса: `T = π * √(a³/(G*M_⊙))`
- Скорость в перигелии (у Земли): `v_p = √(G*M_⊙ * (2/R_⊕ - 1/a))`
- Скорость в афелии (у Марса): `v_a = √(G*M_⊙ * (2/R_Марс - 1/a))`

### 5. Мягкая посадка на Марс (этап 3)

На этапе посадки учитывается атмосфера Марса (сопротивление) и работа тормозных двигателей:
m * dv/dt = -u * dm/dt - m*g_Марс - 1/2 * C_d * ρ * A * v²

где:
- `g_Марс` — ускорение свободного падения на Марсе,
- `C_d` — коэффициент лобового сопротивления,
- `ρ` — плотность атмосферы,
- `A` — площадь поперечного сечения.

Для мягкой посадки `v_конечная ≈ 0`.

## Метод 1. Аналитическое решение (упрощённое)

### Этап 1. Вертикальный взлёт (без атмосферы)
- Используем решение уравнения Мещерского для постоянного расхода топлива.
- Определяем время работы двигателей для достижения орбитальной скорости.

### Этап 2. Гелиоцентрический перелёт
- Расчёт гомановской траектории: требуемый приращение скорости у Земли и у Марса.
- Время перелёта: `T_перелёт = π * √(a³/(G*M_⊙))`.

### Этап 3. Посадка на Марс (без атмосферы)
- Уравнение движения с тормозной тягой и марсианской гравитацией.
- Определение необходимого расхода топлива для мягкой посадки.

---

## Метод 2. Численное моделирование (с учётом дополнительных факторов)

### Этап 1A: Старт многоступенчатой ракеты
- Моделируется последовательное сбрасывание ступеней, изменение массы и тяги.
- Учёт сопротивления атмосферы: сила сопротивления `F_сопр = 1/2 * C_d * ρ(h) * A * v²`.

### Этап 2B: Учёт притяжения планет
- Решается система уравнений движения в гелиоцентрической системе с добавлением возмущений от Земли и Марса (ограниченная задача трёх тел).

### Этап 3C: Моделирование разворота и посадки
- Корабль моделируется как цилиндр, учитываются моменты инерции.
- Система ориентации: управляющие моменты от двигателей малой тяги.
- Уравнения вращательного движения:
I * dω/dt = M_упр + M_внеш

- Совместное интегрирование поступательных и вращательных уравнений.

---

## Проверка законов сохранения

- На этапе 2 (без двигателей) полная механическая энергия в гелиоцентрической системе должна сохраняться.
- Импульс системы "корабли+истекающие газы" на этапах 1 и 3 контролируется.
- Для этапа 2B (с притяжением планет) проверяется баланс энергии с учётом потенциалов всех тел.

---

## Сравнение подходов

- **Аналитический метод** даёт быстрые оценки характеристик полёта (скорости, время, масса топлива), но не учитывает многие реальные факторы.
- **Численное моделирование** позволяет учесть атмосферу, многоступенчатость, притяжение планет, ориентацию корабля, но требует больших вычислительных ресурсов и точного задания параметров.
